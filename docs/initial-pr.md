# Team Memory v1

Добавляет общую Markdown-базу задач и знаний: агент сопоставляет переданные материалы
с существующими записями и предлагает изменения через PR. Python проверяет структуру
и предоставляет полный поиск с фильтрами, aliases и пересоздаваемым JSON-каталогом.

В составе: схемы и десять шаблонов, reader/валидатор/поиск, канонический skill с
подключением к агентскому harness, правила смысловой сверки, CI, конфигурация защиты main и тесты.
Рабочая база пустая; демонстрационные данные изолированы в tests/fixtures/demo.

Источники: docs/2026-10-19-team-memory-plan.md и прямой запрос пользователя реализовать.
Пропущенные повторы: не применимо к первоначальной реализации.

## Открытые вопросы и выпуск

До открытия PR нужно восстановить GitHub auth, создать приватный remote и получить
его фактический base. Remote CI и защита main пока не подтверждены. Реальные дейли
команды и GigaCode не проверены. Подробности: docs/verification.md.

Исходный локальный bootstrap SHA: `70bd6dd698b1e0b7752217130d56dd92891fa779`.
SHA последней сверки с удалённой основной веткой: **сверка ещё не выполнена, remote отсутствует**.
Попытки удалённой сверки: 0. Перед публикацией обновить эти поля фактическими значениями.
Merge выполняет человек после актуального CI, review и сверки SHA.
